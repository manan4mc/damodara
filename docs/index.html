Damodara

Damodara is an open-source backup plugin for Minecraft Paper servers. It creates ZIP backups of your server files, on a schedule or whenever you ask for one. Once the server owner connects their Google Drive account, Damodara transfers each completed backup archive to that Drive.

Who it's for

Damodara is for people who run their own Paper server and want backups stored somewhere off the machine. You should be comfortable with the server console and the plugin's config file.

How it works

  • Damodara makes a copy of your server files while the server keeps running.
  • When the backup finishes, it is packed into a timestamped ZIP archive.
  • After you have connected Google Drive, the finished archive is uploaded to your Drive.

Because the copy is made while the server is live, backups are best-effort. Files that change during the copy may not all match the same moment. Check your backups and test a restore before you rely on them.
